## Overview

A responsive, web-based todo-list application that enables users to create and manage projects and todos. Users can add, edit, and delete todos, view detailed todo information, and organize tasks within projects.


## Live Demo

Visit the website: [Live Demo](https://aderitomarrime.github.io/todo-list/)


## Features

- Clean and intuitive user interface
- Fully responsive design
- Dynamic, interactive functionality
- Data persistence using localStorage

## Installation

To run this project locally, follow these steps:

1. Clone the repository:

```sh
git clone https://github.com/aderitomarrime/todo-list.git
```

2. Navigate to the project 
```sh
cd todo-list
```
3. Install dependencies (requires Node.js installed)
```sh
npm install
```

4. Run the development server
```sh
npm run start
```

5. Open your browser at http://localhost:8080


## How to use

1. Open the website in your browser.
2. Add a todo by clicking the New Task button and completing the form.
3. Update a todo's status by clicking its checkbox.
4. View detailed information about a todo by clicking the eye icon.
5. Edit a todo by clicking the pencil icon and updating the form.
6. Delete a todo by clicking the trash icon.
7. Add a new project by clicking the New Project button and completing the form.
8. Switch between projects by clicking on the project name.
9. Delete a project by clicking the trash icon.
